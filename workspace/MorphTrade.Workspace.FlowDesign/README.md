# MorphTrade.Workspace.FlowDesign

Experimental workspace for designing and testing trading flows and strategies.

## Purpose

Provides a sandbox environment for prototyping trading flows, strategy composition, and backtesting logic before production integration.

## Features

- Design and test trading strategies
- Experiment with flow compositions
- Prototype decision-making logic
- Test strategy behavior with market data

## Usage

```bash
dotnet run --project workspace/MorphTrade.Workspace.FlowDesign
```

## Workflow

Use this workspace to:
- Design complex trading strategies
- Test flow orchestration patterns
- Validate strategy logic
- Iterate on trading algorithms

Once validated, integrate flows into the main framework for production use.

# MorphTrade.Workspace.Flows.Backtests

A sandbox environment for backtesting trading flow strategies against historical OLHCV data.

## Purpose

This workspace provides a standalone executable for testing and validating trading flow implementations (such as EMA crossover strategies) using historical market data. It enables rapid iteration and performance analysis of trading algorithms without requiring live market connections.

## Features

- **Flow Backtesting**: Execute trading flows against historical data to evaluate strategy performance
- **Configurable Strategies**: Easily configure flow parameters (e.g., EMA periods, unit sizes) via dependency injection
- **Test Data Management**: Load OLHCV datapoints from JSON files for reproducible testing
- **Results Export**: Automatically generates timestamped JSON outputs containing:
  - `decisionList.json` - Trade decisions and signals generated by the flow
  - `backtestResults.json` - Performance metrics and analytics from the backtest run

## Current Implementation

The sandbox currently implements the **EMA Crossover Simple** strategy with the following default configuration:

- Fast EMA: 5 periods
- Slow EMA: 20 periods
- Default unit size: 10

## Configuration

Edit `appsettings.json` to customize:

```json
{
  "TestDataOptions": {
    "TestDataJsonAbsolutePath": "test_data.json"
  },
  "ResultsDirectory": "/path/to/output/directory"
}
```

- **TestDataJsonAbsolutePath**: Path to JSON file containing OLHCV datapoints
- **ResultsDirectory**: Directory where backtest results will be saved (defaults to temp directory if not specified)

> [!TIP]
> **Recommended Setup for Analytics Integration**
> 
> For the best workflow, clone the [OpAn.App.MorphTrade.Tool.BacktestAnalytics](https://github.com/OpAn/OpAn.App.MorphTrade.Tool.BacktestAnalytics) repository and set your `ResultsDirectory` to point to its `databank` subdirectory:
> 
> ```json
> "ResultsDirectory": "/path/to/OpAn.App.MorphTrade.Tool.BacktestAnalytics/databank"
> ```
> 
> This allows you to:
> 1. Run backtests from this workspace (results saved to `databank/`)
> 2. Use the BacktestAnalytics tool to visualize results with interactive candlestick charts and analytics overlays
> 
> The analytics tool automatically reads from the `databank` directory and provides rich visualizations of your backtest performance.

## Running the Backtest

```bash
dotnet run --project workspace/MorphTrade.Workspace.Flows.Backtests
```

Results will be written to timestamped subdirectories in the configured `ResultsDirectory`:
```
ResultsDirectory/
└── 2024-01-01T14-30/
    ├── decisionList.json
    └── backtestResults.json
```

## Test Data Format

The `test_data.json` file should contain an array of OLHCV datapoints:

```json
[
  {
    "Timestamp": 1704080700,
    "Open": 680.13,
    "High": 684.75,
    "Low": 679.25,
    "Close": 684.75,
    "Volume": 87604
  }
]
```

Timestamps are in Unix epoch seconds and are automatically converted to `DateTime` objects during deserialization.

## Adding New Flows

To test a different trading flow:

1. Register your flow implementation in `Program.cs`:
   ```csharp
   builder.Services.AddScoped<IFlow, YourCustomFlow>();
   ```

2. Configure flow-specific options:
   ```csharp
   builder.Services
       .AddOptions<YourCustomFlowOptions>()
       .Configure(options => { /* configure */ });
   ```

3. Run the backtest to generate results

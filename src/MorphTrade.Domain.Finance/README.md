# MorphTrade.Domain.Finance

Core finance domain abstractions and models.

## Purpose

Provides foundational finance domain interfaces and assembly markers for the finance-related modules.

## Key Components

- **IFinanceDomainAssemblyMarker** - Assembly marker interface for dependency scanning

## Usage

This project serves as a base for finance-related domain modules like `MorphTrade.Domain.Finance.Bank`. Reference this when building finance domain extensions.
